## Provenienz: wichtig für künftige Releases

Der Release-Tag zeigt auf einen Commit des **öffentlichen Dokumentations-Repositories**, nicht auf den Ursprungs-Commit des privaten App-Quellcodes. Für einen reproduzierbaren Release müssen **privater Source-SHA**, Version, Build-Rezept, Paket-Hash, Signatur-Key-ID und unabhängige QA eindeutig zusammen dokumentiert werden. Ein identischer Versionsstring in einem privaten Feature-Branch ist kein sicherer Herkunftsnachweis.
